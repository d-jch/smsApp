# 产品需求文档（PRD）

## 1. 项目概述

- **项目名称**：Sequencing Management System
- **技术栈**：Deno + Fresh + SQLite + Preact + Tailwind CSS 4 + DaisyUI 5 +
  TypeScript
- **项目目标**：打造现代化 Sanger
  测序预约管理系统，实现样本、预约、实验流程的数字化管理
- **可扩展性**：支持未来扩展至 NGS 测序等

## 2. 产品目标

1. 提升实验室测序服务管理效率，减少人为错误
2. 优化预约流程，提升用户体验
3. 实现测序过程全程数字化追踪与管理

## 3. 用户故事与角色

- **普通用户**：可在线预约测序服务，提交样本信息，查询进度，下载结果
- **实验室管理员**：管理所有预约和样本，调度资源，统计分析
- **测序技术员**：接收样本，操作实验，上传结果，记录质控
- **项目负责人**：查看统计报表，分析服务质量与效率

## 4. 功能需求

### 4.1 用户角色与权限

- **系统管理员**：账号管理、角色配置、参数设置、数据备份
- **实验室管理员**：预约审核、样本管理、资源调度、数据统计
- **测序技术员**：样本处理、实验操作、结果上传、质控记录
- **普通用户**：服务预约、样本提交、进度查询、结果下载

### 4.2 核心功能模块

- **用户认证**：注册、登录、角色权限、个人信息、密码找回
- **预约管理**：预约申请、状态管理、审核流程、变更取消
- **样本管理**：信息登记、条码管理、存储位置、状态跟踪、批量导入
- **实验管理**：任务分配、过程记录、质控数据、结果上传、报告生成
- **数据统计**：预约统计、样本处理统计、质量分析、报表导出

## 5. 非功能需求

- **性能**：页面加载 < 2秒，接口响应 < 500ms，数据库查询 < 200ms
- **安全**：用户认证与授权、HTTPS加密、敏感信息加密存储、操作日志、数据定期备份
- **可用性**：可用性 > 99.9%，维护时间每月 < 4小时，数据每日备份，故障恢复 < 4小时

## 6. 主要业务流程说明

1. 用户注册/登录，分配角色
2. 用户创建预约，录入样品
3. 用户为样品添加引物
4. 技术员创建实验（板），分配样品和引物到孔，生成反应记录
5. 技术员上传测序结果
6. 用户/管理员查询进度与结果
