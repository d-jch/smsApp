# Contributing

Thanks for your interest in contributing. Please follow these guidelines:

- Fork and create a branch for your work (e.g. `feature/xxx` or `fix/xxx`).
- Keep PRs small and focused.
- Run tests and linters before opening a PR:

```bash
deno fmt --check
deno lint
deno test
```

- For dependency upgrades, Renovate will open PRs automatically. Review CI results before merging.
